# 小鈴鐺資訊整合

中學家長與學生查閱行事曆、課務學習、校園事務與公告的公開資訊入口。

目前為第一階段網站框架，內容均為示意占位，待正式資料確認後置換。

## 網站架構

- 首頁：近期重點與四大資訊入口
- 行事曆：考試、活動、假期與截止日
- 課務學習：課表、考試範圍、作業與學習資源
- 校園事務：交通、制服、餐飲、請假與行政流程
- 公告：依國中部、高中部與年級整理通知

## 資料安全

公開 repository 不放學生姓名、班級名冊、聯絡方式、帳密、QR Code、成績、健康資料或群組對話原文。

## 本機開發

這是無需安裝套件的純靜態網站。可直接用任意靜態網站伺服器預覽，例如：

```bash
python -m http.server 8000
```

示意資料集中在 `src/data.js`，後續填資料時通常不需修改版面元件。
