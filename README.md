# 小鈴鐺資訊整合

中學家長與學生查閱行事曆、課務學習、校園事務與公告的公開資訊入口。

目前已匯入國中部活動資料，正式開放首頁與行事曆；課務、校園事務與公告仍保留未開放骨架。詳細架構、資料格式、執行與維護方式見 [專案說明](PROJECT_GUIDE.md)，後續協作背景見 [專案記憶](PROJECT_MEMORY.md)。

## 網站架構（含尚未開放項目）

- 首頁：近期重點與四大資訊入口
- 行事曆：考試、活動、假期與截止日
- 課務學習：保留骨架，尚未開放
- 校園事務：保留骨架，尚未開放
- 公告：保留異動資料，尚未開放

## 資料安全

公開 repository 不放學生姓名、班級名冊、聯絡方式、帳密、QR Code、成績、健康資料或群組對話原文。

## 本機開發

這是無需安裝套件的純靜態網站。可直接用任意靜態網站伺服器預覽，例如：

```bash
python -m http.server 8000
```

活動資料集中在 `src/data.js`，後續填資料時通常不需修改版面元件。首頁會考日期另外位於 `src/app.js`。本次 checkout 另附免套件 Node.js 預覽工具，詳見專案說明。
